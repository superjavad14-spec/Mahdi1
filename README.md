# موزه سه‌بعدی مهدویت

این مخزن شامل وب‌سایت آموزشی فارسی موزه سه‌بعدی مهدویت است. راهنمای اجرا، وابستگی‌ها، امکانات و محدوده منابع در ادامه آمده است.

## اجرای آنلاین

برای انتشار، در GitHub به مسیر **Settings → Pages** بروید و در بخش Build and deployment گزینه **Deploy from a branch**، شاخه **main** و پوشه **/(root)** را انتخاب و ذخیره کنید. پس از پایان انتشار، سایت در نشانی زیر در دسترس خواهد بود:

https://superjavad14-spec.github.io/Mahdi1/

## اجرای محلی

به‌دلیل محدودیت بارگذاری ماژول‌های JavaScript از نشانی `file://`، پروژه را با یک وب‌سرور ایستا اجرا کنید:

```bash
python -m http.server 8000
```

سپس در مرورگر به `http://localhost:8000` بروید.

## وابستگی و حالت جایگزین

- موتور سه‌بعدی: **Three.js 0.166.1** از CDN نسخه‌بندی‌شده jsDelivr بارگذاری می‌شود.
- بارگذاری Three.js به اتصال اینترنت نیاز دارد. در صورت در دسترس نبودن CDN یا WebGL، فهرست تالارها، متن‌ها، منابع، اسلایدشو و تنظیمات در نمای دوبعدی سبک باقی می‌مانند.
- معماری، ویترین‌ها، مدل‌های نمادین و نمودارهای روی نمایشگرها در کد ساخته می‌شوند؛ فایل مدل یا تصویر ثالث در این نسخه استفاده نشده است.
- فونت از فونت‌های سیستمی مرورگر استفاده می‌کند.

## امکانات

- ۱۳ تالار موضوعی و ۴۸ اسلاید آموزشی
- دوربین هدایت‌شده و صحنه اختصاصی هر تالار در حالت Three.js
- نقشه مفهومی تالارها، کتابخانه منابع و خط زمانی ۲۴‌محوری
- مطالعه بیشتر و نمایش ارجاع‌های اسلاید
- تنظیمات نمایش متن، کیفیت گرافیکی و حرکت دوربین
- ذخیره پیشرفت و تنظیمات در LocalStorage
- تالار پایانی با مرور تالارهای بازدیدشده و خودآزمایی

## محدوده پژوهش و منابع

محتوا بر پایه دو جلد بارگذاری‌شده «نگین آفرینش، درسنامه دوره عمومی معارف مهدویت» نوشته محمدامین بالادستیان، محمدمهدی حائری‌پور و مهدی یوسفیان تنظیم شده است. ارجاع‌های جلد اول با شماره صفحه چاپی کتاب درج شده‌اند. جلد دوم PDF تصویری بود؛ فهرست مطالب و نمونه‌هایی از درس «سازمان وکالت» بررسی شد و محدودیت بررسی کامل آن در کتابخانه منابع برنامه ذکر شده است.

این محصول خلاصه آموزشی است، نه تصحیح انتقادی روایات یا ارزیابی جامع اسناد. درباره موضوعات اختلافی، تعیین وقت ظهور، تطبیق نشانه‌ها و جزئیات پایان دوران با احتیاط عمل شده است.

## ذخیره‌سازی

پیشرفت و تنظیمات فقط در حافظه محلی همان مرورگر ذخیره می‌شوند. پاک کردن داده‌های سایت یا استفاده از مرورگر/دستگاه دیگر، این پیشرفت را منتقل نمی‌کند.
