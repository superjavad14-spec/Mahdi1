# موزه سه‌بعدی مهدویت

وب‌سایت آموزشی سه‌بعدی معارف مهدویت — بر پایه درسنامه‌های «نگین آفرینش (۱)» و «نگین آفرینش (۲)» (مرکز تخصصی مهدویت حوزه علمیه قم).

## ساختار
- `index.html` نقطه ورود است.
- `main.js` کل برنامه (موتور Three.js + رابط کاربری) به‌صورت باندل‌شده است.
- `styles.css` شیوه‌نامه رابط.
- `images/` تصاویر مفهومی تالارها (تولیدشده با ابزار هوش مصنوعی؛ بازسازی مفهومی، نه سند تاریخی).
- `fonts/` فونت وزیرمتن (مجوز OFL).

## انتشار در GitHub Pages
1. یک مخزن بسازید و همه فایل‌های همین پوشه را در ریشه آن قرار دهید.
2. در Settings → Pages، گزینه «Deploy from a branch» را انتخاب و شاخه اصلی (`main`) و پوشه ریشه (`/`) را مشخص کنید.
3. اگر مخزن در زیرمسیر منتشر شود (مثل `username.github.io/repo`)، همه مسیرها نسبی‌اند و بدون تغییر کار می‌کنند.

همچنین برای اجرای محلی کافی است یک سرور ایستا اجرا کنید:
```
bunx serve .
```
(مسیر file:// به دلیل محدودیت بارگذاری تصاویر توصیه نمی‌شود.)

## نحوه استفاده
- در رایانه: کلید Space = اسلاید بعدی؛ پیکان چپ/راست = جابه‌جایی؛ کشیدن ماوس = گردش نگاه.
- در موبایل: دکمه‌های لمسی بزرگ «قبلی» و «بعدی».
- دکمه «نقشه» یا «فهرست»: انتخاب مستقیم هر تالار؛ دکمه «مرکز»: بازگشت به تالار مرکزی.
- تنظیمات: کیفیت گرافیک (پایین/متوسط/بالا)، مکان و اندازه پنل متن (یک‌پنجم/یک‌سوم)، کاهش حرکت، پاک‌کردن پیشرفت.
- پیشرفت و تنظیمات در LocalStorage مرورگر ذخیره می‌شود؛ بدون نیاز به Backend.

## نکات فنی
- اگر مرورگر از WebGL پشتیبانی نکند، نسخه دوبعدی سبک به‌طور خودکار فعال می‌شود (همچنین با پارامتر `?mode=2d`).
- صدا: این نسخه فایل صوتی ندارد و دکمه صوتی ندارد.

## محتوا
سیزده تالار موضوعی + ورودی، کتابخانه منابع، تالار پایانی و تالار مرکزی؛ ۵۷ ایستگاه و ۱۶۰ اسلاید آموزشی.
همه نقل‌ها با ذکر منبع (مطابق ارجاعات متن کتاب‌های نگین آفرینش) ارائه شده‌اند و تصاویر، بازسازی مفهومی‌اند.
